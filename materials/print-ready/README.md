## Printing

Use US Letter paper (8.5 x 11 inches) and print at actual size (100%). The complete print kit contains all four pages; the individual files are available for selective printing.

## Keeping files current

This folder contains one current version of each listed file. Replace files at their existing paths when updating them, rather than adding dated or numbered copies. Earlier revisions, if any, remain in Git history.
